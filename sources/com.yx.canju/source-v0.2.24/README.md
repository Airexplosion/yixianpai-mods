换边、离场、发牌、炼化或修改对局属性会使旧结果失效；一键摆牌每一步重新检查局面，避免把上一方的解摆到下一方。只调整同一牌池的摆放顺序可以复用结果。

- 摆牌界面左上角设置 / 聊天 / 秘籍按钮组下方多一个 **「残局求解」** 文字按钮（热键 `Ctrl+Alt+J` 同一动作）。
- 第一次点：只打开左侧游戏原生**战斗秘籍抽屉**，推荐列表为空。读局面，不提交计算。
- 点抽屉顶部 **「求解」**：交给随 mod 附带的战斗计算器原生库（`native/YxBattleSim.dll`，NativeAOT，多线程），**先手、后手都算**，每行显示两种战果。默认先手 / 后手各50%参与排序；原生残局 / 复盘可在 `solve.currentOrderWeightPercent` 调整当前顺序的排序占比，另一种仍计算。改变修为后的最终摆法应重新求解，因为炼化也会改变牌池。
  过程中显示 toast 进度，按钮显示「求解中…」并禁用重复提交；算完显示前几名摆法（真卡图，每行备注先手 / 后手胜负与剩血，第一名下面一行是「留在手牌」）。抽屉是本地生成的，不往服务器存秘籍。
- 之后再点入口：局面没变（同一套牌、同一个对手）直接打开上次的结果；局面变了显示空列表，仍须点「求解」才计算。
- 抽屉里的按钮：
  - 每条方案右上方的 **一键摆牌**：按点击的那条方案摆好，留手牌行没有按钮。只走游戏自己的移牌入口（`CardPanel.MoveToGrid` / `MoveToHand`，与玩家拖牌相同），
    一步一个动作、等生效再下一步；先收回多余的牌再逐格放（不会超消耗 / 持续上限），从不把牌拖到同 id 的牌上（那会合成升级）。
  - 顶部 **求解**：已有结果时点击也会强制重算。

胜负按游戏规则判：剩血多者胜（没人阵亡也一样），同血判先手 —— 没有平局。结果是模拟，仅供参考。

## 构建与打包（仓库根目录）

```powershell
# 1. 战斗计算器原生库（sim/ 在主仓库本机，gitignore；需要 VS2022 C++ 工具链，报 vswhere 找不到时先把
#    ${env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer 加进 PATH）
dotnet publish sim/Yx.BattleSim.Native -c Release
Copy-Item sim/Yx.BattleSim.Native/bin/Release/net8.0/win-x64/publish/YxBattleSim.dll mods/com.yx.canju/native/

# 2. 数据（抽自游戏，随发布包分发、不进仓库）
Copy-Item sim/data/battle_config.local.json mods/com.yx.canju/data/battle_config.json
Copy-Item sim/data/card_effects.local.json  mods/com.yx.canju/data/card_effects.json

# 3. mod
dotnet build mods/com.yx.canju/Canju.csproj -c Release
tools/yx-patch/bin/Release/net8.0/yx-patch check mods/com.yx.canju/plugins/Canju.dll
tools/yx-patch/bin/Release/net8.0/yx-patch pack mods/com.yx.canju
```

游戏更新后要重抽数据、重发版本（`native/` 与 `data/` 在 `.gitignore` 里）。
