# 败局错题本

把自己打输的一轮留到下次重做。打开题目时，自己的牌桌从空格开始，对手牌序、双方状态、可用卡牌和先后手都取自当轮战绩。交卷后看自己这次怎么摆、当时怎么摆，以及一种能赢的摆法。

## 安装和试做

1. 在 Steam 版弈仙牌 MOD 管理器安装并启用「残局求解」0.2.25。
2. 把 `dist/com.yx.mistakebook-0.1.1.zip` 拖进管理器，启用「败局错题本」，通过管理器启动游戏。
3. 大厅点「败局错题本」或按 `Ctrl+Alt+M`。空题本也能点「试做示例」，体验一关两格的云剑题。

## 收题与重做

- 打开自己的战绩详情，切到输掉的一轮，点「收藏本轮」。系统先复验原摆法，再搜索并复验一种赢法。成功时显示「已收藏」。搜索期间可取消，切换轮次或关掉详情也会停止验题。
- 题本按收藏时间倒序排列。点题后选中牌位，再点手牌，系统自动移到下一格。「本格留空」按普通攻击结算。「双方状态」可查双方修为、命元、仙命和天衍。
- 交卷按自己摆的牌重新计算。只要该摆法在历史先后手下确实能赢，就算攻克。若这次摆法触发随机效果，会提示调整，保留作答且不计入尝试次数。交卷后可看三套牌序，再次盲摆会重新隐藏答案。
- 个人题目及成绩通过管理器保存在本机，重启后可继续。容量受管理器每个 Mod 的 256 KB 限额约束，装满后可手动移除旧题。示例独立于收藏和成绩。

## 规则范围

0.1.1 对应战绩版本 `001.0008.0008` 和残局求解 0.2.25，使用该版战绩读取器及同版计算核。只接纳我方明确输给对手、先后手完整、原摆法复算确实落败且搜到已复验赢法的轮次。搜索中遇到随机分支也会跳过该轮。记录里的格数、重复牌、牌级和消耗／持续牌数量上限都参与作答。固定当轮资源和对手，只练摆牌。作答在错题本面板内完成，练习场与整局复盘均为可选。

`001.0008.0006` 及 `001.0008.0007` 规则下已有的题目按旧版存档显示，可查看双方牌序、原参考答案和成绩，但不使用新版规则重新验算。

## 构建

在这个工作区运行 `./build.ps1`。脚本从并列的 SDK 与加载器工程取得编译引用，默认使用工作区内归档的残局求解 0.2.25。也可传 `-CanjuDir <解压后含 manifest.json 的目录>`。如果游戏引用由 Mod 管理器生成在其他目录，可传 `-YxRefs <引用目录>`，编译和测试会使用同一套引用。脚本校验上游四个文件的 SHA-256，运行 Release 编译、测试和 IL 检查后打包。安装包带同版的计算核和两份规则数据，独立调用定盘预测。战绩读取器由已安装的残局求解提供。
